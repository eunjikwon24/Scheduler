## 1. 처음 한 번만 하는 설정

### 아이폰에서 앱처럼 쓰기
Safari로 주소에 들어간 뒤 → 아래 **공유 버튼** → **홈 화면에 추가**.
아이콘이 생겨서 앱처럼 열립니다.

### 기기 연결하기 (동기화)
1. 오른쪽 위 저장 표시(`저장됨` 옆) 를 누릅니다.
2. **GitHub로 자동 동기화** 칸에 토큰을 붙여넣고 **연결하기**.
3. "연결됐어요" 가 뜨면 끝. 그 뒤로는 자동입니다.

> 토큰은 **classic token** 이어야 하고 권한은 **`gist` 하나만** 켜면 됩니다.
> 만드는 방법은 `SETUP.md` 에 있어요. **토큰은 누구에게도 보여주지 마세요.**
> 새 기기에서는 한 번씩만 넣으면 됩니다.

### 이름 바꾸기
왼쪽 위 제목(`하루 트랙 ✎`)을 누르면 이름을 바꿀 수 있어요. `은땅이의 하루` 처럼요.

## 2. 할 일 쓰기

**오늘 할 일** 칸에 적고 `추가`.

### 시간을 같이 적으면 자동으로 시간표에 들어갑니다
제목에 시간을 쓰면 알아서 알아듣고 **시간 부분은 제목에서 빠집니다.**

| 이렇게 쓰면 | 이렇게 들어갑니다 |
|---|---|
| `3시 회의` | 15:00–16:00 · 회의 |
| `9:30~11:00 실험` | 09:30–11:00 · 실험 |
| `14:00 세미나` | 14:00–15:00 · 세미나 |
| `3시 반 병원` | 15:30–16:30 · 병원 |
| `2시간 코딩` | 코딩 (시각 없이 2시간짜리로) |
| `30분 산책` | 산책 (30분짜리) |

- 1시~7시는 **오후**로 봅니다. 오전이면 `9am` 이나 `09:00` 처럼 써주세요.
- 시간을 직접 고르고 싶으면 옆의 **시계 칸**을 쓰면 됩니다.
- 옆의 **태그**(공부 / 일 / 운동 / 집안일 / 약속 / 미팅 / 쉼)로 색이 정해집니다.

### 할 일로 할 수 있는 것

| 누르는 곳 | 하는 일 |
|---|---|
| `✓` 동그라미 | 완료 / 완료 취소 |
| 제목 | — |
| `✎` | 제목·시간·태그 고치기 |
| `▶` | 시간 재기 시작 (`■` 로 멈춤) |
| `⠿` 를 잡고 위아래 | 순서 바꾸기 |
| `×` | 지우기 (⌘Z 로 되돌리기) |

- **시간순 정렬** — 시간 있는 것부터 순서대로 정리해줍니다.
- **남은 일 내일로** — 오늘 못 끝낸 걸 통째로 내일로 넘깁니다.
- 아래 `+ 이메일 정리` 같은 버튼은 자주 쓰는 일 빠른 추가입니다.

## 3. 시간표 보기

오른쪽 **오늘 시간표**에 시간이 정해진 일과 수업이 블록으로 보입니다.

- 블록을 **잡고 위아래로 끌면** 시간이 바뀝니다. **5분 단위**로 딱딱 붙어요.
- 블록을 **짧게 누르면** 수정 창이 열립니다.
- 수업 블록은 움직이지 않습니다 (수업 시간표에서 고쳐주세요).
- 겹치는 일정은 나란히 놓입니다.

---

## 4. 주 보기 · 월 보기

위쪽 `주` / `월` 로 바꿉니다.

- **주 보기**: 일곱 개 날짜 칸. `‹` `›` 로 앞뒤 주로.
- **월 보기**: 한 달 전체. `‹` `›` 로 달을 넘기고, **연도도 계속 넘어갑니다.**
  - 완료한 일도 **밑줄 없이** 보여요. 무슨 일이 있었는지 보려는 거니까요.
  - 반복되는 수업은 월 보기에는 안 나옵니다 (너무 빽빽해져서요).
  - **한국 공휴일은 빨간 날**로 표시되고 이름도 같이 나옵니다.
- **오늘로** 를 누르면 언제든 오늘로 돌아옵니다.

## 5. 수업 시간표

오른쪽 **수업 시간표** 를 펼치세요.

1. 맨 위 **학기 시작일 ~ 종료일** 을 정합니다.
2. 수업 이름 · 요일 · 시작~끝 시간 · 강의실 을 넣고 `추가`.

그러면 **그 학기 동안 해당 요일마다** 자동으로 시간표에 뜹니다.
학기가 끝나면 저절로 사라져요. 학기를 비워두면 계속 반복됩니다.

## 6. 기간 일정 (출장·여행)

**기간 일정** 을 펼치고 `부산 출장` 처럼 이름 + 시작일 ~ 종료일 을 넣으면,
그 기간의 모든 날 위에 띠로 표시됩니다. 며칠짜리인지도 같이 나와요.

## 7. 잡일 목록

날짜는 안 정했는데 언젠가 해야 하는 일들.
왼쪽 **잡일 목록** 에 쌓아두고 하나씩 `✓` 하면 됩니다. 날짜를 옮겨도 그대로 남아 있어요.

## 8. 메모와 노트

### 메모
학번, 강의실, 마감일처럼 **늘 보이면 좋은 짧은 정보**. 항상 화면에 떠 있습니다.

### 노트
위쪽 **📓 노트** — 길게 정리할 내용은 여기에. 여러 장 만들고 검색도 됩니다.

### 둘 다 서식이 됩니다

| 버튼 | 기능 |
|---|---|
| **B** / *I* / <u>U</u> / ~~S~~ | 굵게(⌘B) · 기울임(⌘I) · 밑줄(⌘U) · 취소선 |
| 🖍 / 🎨 | 형광펜 · 글자색 |
| 제목 / • / 1. | 소제목 · 글머리 기호 · 번호 매기기 |
| ✕ | 서식 지우기 |
| ⭐️ ✅ 📌 🔥 … | 아이콘 바로 넣기 |

## 9. 스티커

위쪽 **🎀 스티커** → 날짜에 붙일 스티커를 고르세요. 다시 누르면 떼집니다.
동물 · 마음 · 먹을것 · 날씨·계절 · 일상 · 표정 여섯 묶음이 있어요.
붙인 스티커는 주 보기와 월 보기 날짜 칸에 같이 보입니다.

---

## 10. 꾸미기 — 색·글자 크기·배경·다크모드

위쪽 **🎨 꾸미기**:

- **색 테마 10가지** — 자두 · 벚꽃 · 살구 노을 · 버터 크림 · 숲 그늘 · 바다 유리 · 밤하늘 파랑 · 포도 젤리 · 장미 · 먹지 그레이
- **글자 크기** — 작게 / 보통 / 크게 / 아주 크게
- **배경 그림** — 테마에 맞는 은은한 그림을 켜고 끕니다

**밝게 / 어둡게**는 따로예요. 오른쪽 위 **🖥 버튼**을 누를 때마다
`시스템 → 밝게 → 어둡게` 로 돌아갑니다. (`시스템`은 맥·아이폰 설정을 따라갑니다.)

색·이름·스티커는 **모든 기기에 같이 적용**되고, 글자 크기와 밝기는 그 기기에만 저장됩니다.

## 11. 동기화

- 바꾸면 **2.5초 뒤** 자동으로 올라갑니다.
- 다른 기기는 **화면을 볼 때마다, 그리고 45초마다** 확인합니다.
- 두 기기에서 각각 쓴 내용은 **합쳐집니다.** 지운 건 되살아나지 않아요.
- 오른쪽 위 저장 표시를 누르면 **마지막 동기화 시각, 저장 방식, 오류**가 다 보입니다.
  - `↑ 이 기기 내용을 페이지에 올리기` / `↓ 페이지 내용을 이 기기로 가져오기` 로 직접 맞출 수도 있어요.
- **↓ 내보내기 / ↑ 가져오기** 로 파일 백업도 됩니다. (인터넷 없이 옮길 때)

## 12. 단축키와 소소한 기능

| | |
|---|---|
| `⌘Z` | 방금 지운 할 일 되돌리기 |
| `⌘B` `⌘I` `⌘U` | 메모·노트에서 굵게 / 기울임 / 밑줄 |
| **이번 주** 칸 | 요일별로 얼마나 했는지 막대로 |
| **중복 정리** | 메모에 같은 내용이 겹쳐 들어갔을 때 정리 (있을 때만 보입니다) |

## 13. 문제가 생기면

**폰에는 내용이 안 보여요**
→ 폰에서도 토큰을 한 번 넣어야 합니다. 저장 표시 → 토큰 붙여넣기 → 연결하기.

**연결하지 못했어요 (403)**
→ 토큰 종류가 잘못됐습니다. **classic token** (`ghp_` 로 시작) 을 만들고 **`gist` 권한**을 켜주세요.
fine-grained 토큰(`github_pat_`)은 Gist에 안 됩니다.

**토큰을 잃어버렸어요**
→ 새로 만들어서 다시 넣으면 됩니다. **기록은 Gist에 그대로 있습니다.**

**메모를 쓰다가 화면이 끊겨요**
→ 최신 버전에서 고쳐졌습니다. 페이지를 새로고침(⌘R)하고, 맨 아래 버전 표시가 두 기기에서 같은지 봐주세요.

**기록을 직접 보고 싶어요**
→ https://gist.github.com 에서 `haru-track-data` 를 찾으면 됩니다.
